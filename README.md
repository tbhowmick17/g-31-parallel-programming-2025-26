# Heatmap Analysis (OpenMP)

This project contains two OpenMP programs for analyzing a 2D heatmap.

- `heatmap_analysis.c`  
  Full analysis (Task 1.1)

- `heatmap_analysis_quick.c`  
  Early-exit version using an atomic flag (Task 1.2)

---

## Compilation

Compilation can be done either locally or on the Fulda HPC cluster.
